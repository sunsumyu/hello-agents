# 任务 2: 前沿观测与操控技术

【任务概览】
目标：调研最先进的神经元成像与操控技术，明确‘观察’与‘干预’路径。

【新增进展】
1. 观测技术（读取）：
- 大视场双光子成像显微镜：实现活体大脑神经元亚细胞分辨率的钙成像，提供实时高精度观测能力。
- 多色微型化双光子显微镜：进一步提升了设备的小型化与多通道观测能力。
- 功能近红外光谱（fNIRS）：作为光学手段的一部分，参与神经活动的读取与解码。

2. 操控技术（写入）：
- 介观尺度灵长类光遗传技术：实现了对灵长类大脑皮层的长期精准稳定刺激，支持行为诱导，突破了物种限制。
- 靶向纤维激活：通过光遗传学重新激活特定神经纤维（如多巴胺神经纤维），可恢复受损的联想学习行为。

3. 系统集成（闭环）：
- 构建了‘读取-解码-写入’的完整光学链路，通过融合成像（读）与光遗传（写），实现了高精度闭环脑机接口（BCI）的技术路径。
